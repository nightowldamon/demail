EMAIL TEMPLATE BUILDER - USER GUIDE
=====================================

QUICK START
-----------
1. Open index.html in your web browser
2. Select a template from the grid (Newsletter, Promo, Event, or Announcement)
3. Customize the content in the left sidebar
4. Watch the live preview update on the right
5. Click "Copy HTML" when ready
6. Paste directly into Gmail compose or your email service (HubSpot, Mailchimp, etc.)


TEMPLATE TYPES
--------------
• Newsletter - Professional newsletter with hero and multiple sections
• Promo - Product promotion with feature highlights
• Event - Event invitation layout
• Announcement - Clean, simple announcement


AVAILABLE SECTIONS
------------------
Each template consists of modular sections that you can:
• Toggle on/off (eye icon)
• Reorder (up/down arrows)
• Customize completely

Section Types:

1. HEADER WITH LOGO
   - Upload your company logo
   - Set background color
   - Centered layout

2. HERO IMAGE
   - Full-width banner image
   - Optional clickable link
   - Great for main visuals

3. TEXT BLOCK
   - Heading + paragraph content
   - HTML formatting supported: <b>bold</b>, <i>italic</i>, <br> for line breaks
   - Customizable background
   - Perfect for body content

4. CALL-TO-ACTION BUTTON
   - Customizable button text and URL
   - Choose button and text colors
   - Email-client compatible design

5. FEATURES GRID
   - 1 or 2 column layout
   - Up to 4 features with icons
   - Toggle individual features on/off
   - 100x100px square images
   - Great for product highlights

6. DIVIDER
   - Visual separator between sections
   - Customizable color

7. IMAGE + TEXT
   - Side-by-side layout
   - Image left or right
   - Great for feature descriptions

8. FOOTER
   - Company name and address
   - Unsubscribe link (required for compliance)
   - Customizable colors


GLOBAL SETTINGS
---------------
• Brand Color - Your primary brand color
• Background Color - Email background (usually light gray)
• Content Width - Fixed at 600px (email standard)


CUSTOMIZATION TIPS
------------------
✓ Use high-quality images (host them online first)
✓ Keep text concise and scannable
✓ Use your brand colors consistently
✓ Use HTML tags for formatting: <b>bold</b>, <i>italic</i>, <br> for line breaks
✓ Test buttons by clicking in the preview
✓ Always include an unsubscribe link


EMAIL COMPATIBILITY
-------------------
The generated HTML uses:
• Table-based layouts (works in all email clients)
• Inline CSS (no external stylesheets)
• 600px width (standard for emails)
• Compatible with: Gmail, Outlook, Apple Mail, Yahoo, etc.


HOW TO USE IN EMAIL SERVICES
-----------------------------
GMAIL (Direct Paste):
1. Click "Copy HTML" button
2. Open Gmail and click Compose
3. Click in the compose area and paste (Ctrl+V or Cmd+V)
4. The email should appear formatted and ready to send!

HUBSPOT:
1. Create new email
2. Choose "Custom HTML" module
3. Click "Copy HTML" and paste
4. Preview and send

MAILCHIMP:
1. Create campaign
2. Choose "Code your own" template
3. Click "Copy HTML" and paste in code editor
4. Continue to design and send

CONSTANT CONTACT / OTHERS:
1. Look for "Custom HTML" or "Code Editor" option
2. Click "Copy HTML" and paste
3. Preview before sending

NOTE: If pasting into Gmail doesn't work, your browser may not support rich
clipboard. Use the HTML code with email marketing platforms instead.


IMAGE HOSTING
-------------
Email clients don't support embedded images. You must:
1. Upload images to a web server or image hosting service
2. Use the full URL (https://...) in the image fields

Free image hosting options:
• Imgur.com
• ImgBB.com
• Your own website
• Your email service's image library


TEXT FORMATTING
---------------
You can use HTML tags directly in text fields:

• <b>Bold text</b> - Makes text bold
• <i>Italic text</i> - Makes text italic
• <u>Underlined text</u> - Underlines text
• <br> - Line break (new line)
• <strong>Strong text</strong> - Same as bold
• <em>Emphasized text</em> - Same as italic

Example:
Welcome to our <b>amazing</b> newsletter!<br><br>We have <i>exciting</i> news to share.


TROUBLESHOOTING
---------------
Q: Images not showing in preview?
A: Make sure you're using full URLs (https://...)

Q: Preview looks different in my email client?
A: This is normal. Test in your actual email service before sending.

Q: How do I add more than 4 features?
A: Add another Features Grid section (they can be reordered) and customize it.

Q: How do I format text?
A: Use HTML tags like <b>bold</b>, <i>italic</i>, and <br> for line breaks directly in text fields.

Q: Can I save my templates?
A: Copy the HTML and save it to a .html file on your computer for reuse.

Q: The preview has scrollbars?
A: The preview auto-resizes. Try refreshing the page if issues persist.


BEST PRACTICES
--------------
1. Keep emails under 600px wide
2. Use web-safe fonts (Arial, Georgia, etc.)
3. Test on mobile devices
4. Include plain text alternative (in your email service)
5. Follow CAN-SPAM compliance rules
6. A/B test your emails for best results
